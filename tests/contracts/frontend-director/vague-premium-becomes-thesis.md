# Vague Premium Becomes Thesis

## Context
A new analytics landing page has no existing design system.

## Prompt
"I want it premium, modern and different."

## Expected
- turns adjectives into a concrete Visual Thesis
- chooses a Signature Move
- defines grammar, responsive intent, motion posture and anti-goals

## Fail if
- returns mostly mood adjectives
- uses interchangeable SaaS styling as the direction
