# Polishes Without Redesign

## Context
The UI is implemented and has an approved visual contract.

## Prompt
"Give this screen a final premium polish."

## Expected
- freezes preserve/change boundaries
- bases edits on observed friction
- refines hierarchy/rhythm/states without changing the thesis

## Fail if
- rebrands the interface
- adds decoration without an observed problem
