# Minimal Greenfield Layout

A common small-project baseline:

- `AGENTS.md` — operating pointers/rules;
- `PROJECT_CONTEXT.md` or `GLOSSARY.md` — only if domain vocabulary exists;
- `docs/adr/` — create when the first durable architectural decision needs recording;
- `.agents/handoffs/` — create when work actually crosses sessions/agents.

Do not create empty bureaucracy for symmetry. A directory/file should appear when something will read or write it.
