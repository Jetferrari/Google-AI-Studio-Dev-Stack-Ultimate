# Anti-Generic Patterns

Diagnostic questions, not universal bans:
- interchangeable gradient hero treatment;
- excessive glass panels;
- card-per-concept layouts;
- decorative color with no semantic role;
- every section repeating centered headline/subhead/CTA;
- oversized rounded rectangles as the main identity;
- motion added to compensate for weak hierarchy.

Replace generic treatment with a stronger visual thesis, signature move, or information structure.
