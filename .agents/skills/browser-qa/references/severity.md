# Severity

- **Critical** — blocks the primary task, exposes sensitive data, or creates destructive/security-relevant behavior in the tested path.
- **High** — major user path fails or becomes unusable for a meaningful target viewport/input mode.
- **Medium** — functionality remains available but materially degraded, confusing, or inaccessible in an in-scope state.
- **Low** — visible inconsistency/polish defect with limited task impact.

Severity is about user/system impact. Confidence in root cause is reported separately.
