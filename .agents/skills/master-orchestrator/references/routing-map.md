# Routing Map

Use this map only when ownership is not already obvious.

| Signal | Primary |
|---|---|
| vague product requirement / decision | discovery/planning workflow |
| visual direction is open | `frontend-director` |
| fast reversible working slice | `vibe-mode` |
| component source undecided | `ui-library-router` |
| rendered UI needs verification | `browser-qa` |
| existing UI needs finish, direction settled | `premium-web` |
| environment/tool support uncertain | `environment-audit` |
| project lacks agent governance/context | `project-bootstrap` |
| completion/readiness claim | `ship-gate` |
| skill import/quality/portability | `skill-auditor` |
| public publication | `public-repo-gate` |

When a task contains several rows, route by the **next unresolved phase**, not by listing every possibly relevant skill.
