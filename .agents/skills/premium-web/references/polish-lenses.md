# Polish Lenses

Use only the lenses relevant to observed friction.

## Hierarchy
Can a first-time user identify the page's primary object/action without decoration doing all the work?

## Rhythm
Do spacing changes correspond to semantic grouping, or are gaps arbitrary?

## Typography
Are measure, line-height, weight, and scale creating the intended reading order?

## Surfaces
Do borders/backgrounds/elevation clarify grouping, or merely add chrome?

## Density
Does the amount of visible information match frequency of use and user expertise?

## States
Do hover/focus/selected/loading/error changes communicate state without layout jump or ambiguity?

## Restraint
Which decoration can be removed with no loss of hierarchy or meaning? Remove that first.
