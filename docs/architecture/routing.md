# Routing

- unclear problem → `master-orchestrator`
- uncertain environment → `environment-audit`
- project onboarding → `project-bootstrap`
- rapid reversible build → `vibe-mode`
- meaningful visual freedom → `frontend-director`
- component sourcing → `ui-library-router`
- final visual polish → `premium-web`
- runtime/browser validation → `browser-qa`
- phase completion → `ship-gate`
- external skill intake → `skill-auditor`
- public release → `public-repo-gate`

One task normally has one primary skill. A second specialist may validate; it should not compete for authority over the same artifact.
